# Bryan Apellanes

Building the **Bam Toolkit** (`bamtk`) — a self-contained C# .NET framework, SDK, and CLI for rapidly building fully distributed full-stack applications: data modeling/storage, view/UX rendering, and business-logic processing, with its own dependency injection, test framework, and multi-database ORM.

## Currently active

| Repo | What it is |
|---|---|
| [bamtk](https://github.com/BryanApellanes/bamtk) | The toolkit itself — CLI, SDK, and ~44 framework libraries as submodules |
| [bamsvc](https://github.com/BryanApellanes/bamsvc) | Internal backend app-to-app BAM protocol service host |
| [bamdb](https://github.com/BryanApellanes/bamdb) | DAO code generation and multi-database access (MSSQL, Postgres, MySQL, Oracle, Firebird) |
| [bamux](https://github.com/BryanApellanes/bamux) | Console UX host for the toolkit's menu-driven CLI |
| [bamtest](https://github.com/BryanApellanes/bamtest) | Cross-project test discovery and execution tool |
| [bam.protocol](https://github.com/BryanApellanes/bam.protocol) | Core protocol abstractions for the framework's communication layer |

Older experiments (the pre-bamtk `Bam.Net.*` framework and one-off tools) are archived rather than deleted — they're superseded, not maintained.
